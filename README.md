## 1. Project Title

***String Processor — Unit Testing Project***

## 2. What Is This Project?

This is a Python project that works with strings. It can reverse words, count vowels, and count words in a sentence. I also used ***unit testing*** to check whether my functions work correctly.

## 3. Why Did I Make This?

I made this project for learning and practicing Python programming. I wanted to understand how unit testing works and how to find mistakes in my code.

## 4. How to Run It

# Step 1: 
Open the project folder in VS Code.

# Step 2: 
Make sure index.py and test.py are in the same folder.

# Step 3: 
Run the main program using the terminal.

# Step 4:
Run the unit tests

# Step 5:
Check the terminal output to see whether the tests pass or fail.

## 5. What Did I Learn?

-How to create and import Python functions from another file.

-How to write unit tests using Python's unittest module.

-How to use assertions such as assertEqual(), assertTrue(), assertFalse(), and assertRaises().
